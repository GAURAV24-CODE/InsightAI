## 🎯 What is InsightAI?

**InsightAI** is an end-to-end **AI-powered Business Intelligence and Decision Support Platform** that transforms raw business data into:

**Data → Insights → Predictions → Recommendations → Decisions**

Instead of forcing business users to manually clean datasets, build charts, analyze trends, and interpret machine-learning results, InsightAI brings these capabilities together inside one intelligent analytics platform.

### 💡 The Problem

Businesses have plenty of data but often struggle to answer:

* What is happening?
* Why is it happening?
* What is likely to happen next?
* Which customers/products/regions need attention?
* What action should the business take?

### 🚀 The Solution

InsightAI combines:

**Data Wrangling + BI + Machine Learning + Predictive Analytics + Generative AI**

to turn complex datasets into understandable business intelligence.

---

# 🌟 Why InsightAI?

Traditional BI tools primarily answer:

> **"What happened?"**

InsightAI aims to go further:

> **"What happened?" → "Why?" → "What will happen?" → "What should we do?"**

| Traditional Analytics | InsightAI                  |
| --------------------- | -------------------------- |
| Static reports        | Interactive analytics      |
| Manual data cleaning  | Automated data wrangling   |
| Manual KPI creation   | Automated KPI discovery    |
| Charts only           | Charts + AI explanations   |
| Historical analysis   | Predictive analytics       |
| Technical queries     | Natural-language questions |
| Insights              | Insights + recommendations |

# ⚡ Quick Start

### Clone

```bash
git clone https://github.com/GAURAV24-CODE/InsightAI.git
cd InsightAI
```

### Backend

```bash
python -m venv venv
```

### Windows / Git Bash

```bash
source venv/Scripts/activate
```

```bash
pip install -r backend/requirements.txt
```

```bash
uvicorn backend.app.main:app --reload
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
